# v1.0.0 Research code archive

Initial organized archive of the author-supplied Earth Engine and Python workflow for groundwater-related greening and potential GDE analyses across the Mongolian Plateau.

Included: 11 Earth Engine scripts, 7 Python research scripts, portable path configuration, input/output documentation, source provenance, citation preparation and static validation tools.

The supplied Word code was split into executable source files. Fixed local path references were parameterized, optional GUI selection was disabled by default, and a duplicated orphan callback fragment in Earth Engine stage 09 was removed to repair a syntax error. Model thresholds, random seeds and scientific classification rules were retained.

Validation during packaging was limited to syntax, file integrity and helper-tool checks. The complete scientific workflow was not rerun. Required research data, historical runtime versions, complete GWSA preprocessing, original external driver-table generation and the GSFLOW project are not included; see the repository's reproducibility documentation.
